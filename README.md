## ![Logo](https://totheos.com/favicon-16x16.png) [ToTheos](https://totheos.com) &nbsp;&nbsp; Async AI Engineering

An async AI engineering platform that executes prompts, shell commands, validation scripts, and fix prompts inside GitHub infrastructure.

Run autonomous AI agents as Tasks in the background to implement features, refactor repositories, generate tests, and open pull requests automatically.

Built for real software development workflows, not chat.

Prompts entered in the UI are executed as Tasks. Tasks consist of Steps, where each Step executes a shell command. If a Step fails, optional auto-fix prompts can run automatically.

Unit test generation contributions for open-source projects were created with assistance from ToTheos.
